# Scope constraint

- Do only what the user's prompt requests. Do not make changes or perform actions outside that scope.
- Make only the changes strictly necessary to complete the requested task. Do not add unrelated fixes, refactors, features, dependencies, documentation, tests, or database changes.
- Limit validation to the requested changes. A request to review, inspect, or test does not authorize modifying the project or database.
- If an out-of-scope issue is discovered, report it without fixing it. Ask for explicit permission before expanding the scope.
- If the scope is ambiguous, ask for clarification before taking actions that could exceed it.
